## Admin dashboard

Dashboard tổng quan: Thống kê doanh thu, số đơn hàng mới, sản phẩm bán chạy, khách hàng mới.

Quản lý Sản phẩm (Catalog): Danh sách sản phẩm, Thêm/Sửa/Xóa sản phẩm, Danh mục (Categories), Biến thể (Variants -
Size/Color), Kho hàng (Inventory).

Quản lý Đơn hàng (Orders): Danh sách đơn, Chi tiết đơn hàng, Cập nhật trạng thái đơn (Chờ xác nhận -> Đang giao -> Đã
giao -> Hủy).

Quản lý Khách hàng (Customers): Danh sách khách hàng, Lịch sử mua hàng, Khóa/Mở khóa tài khoản.

Cấu hình & Phân quyền (Settings & Auth): Quản lý nhân viên (Admin/Staff roles - nối với Keycloak), Cấu hình khuyến
mãi/mã giảm giá.
