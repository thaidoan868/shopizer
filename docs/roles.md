## Roles

- Super Admin
    - Quyền tối cao: Quản lý nhân viên (thêm/sửa/xóa Admin khác), xem báo cáo doanh thu tổng, cấu hình hệ thống/thanh
      toán, kết nối Keycloak.
- Store Manager
    - Quản lý danh mục, tạo chương trình khuyến mãi, duyệt đơn hàng, quản lý kho. (Không có quyền thêm/xóa nhân viên
      khác).
- Support staff
    - Xem & cập nhật trạng thái đơn hàng (Đã xác nhận, Đã giao...), xử lý đổi trả, xem thông tin khách hàng.
- Warehouse Staff
    - Cập nhật số lượng tồn kho, nhập kho, in phiếu giao hàng.
- Customer
    - Xem sản phẩm, đặt hàng, quản lý địa chỉ, xem lịch sử đơn hàng cá nhân.
